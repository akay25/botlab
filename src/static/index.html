Task 1 — typing waiting

Type a name and an email address. The page measures how long each key is held and how long the gaps between keys are.

Task 2 — aimed movement 0 of 3

Click each of the three circles, in any order. Because the page knows where each target sits, it can measure how the pointer approached it: the curve of the path, whether it overshot, and whether it corrected.

Task 3 — drag, optional waiting

Drag the slider to roughly 70. This one is optional; skip it if your tool cannot drag. Sustained movement with the button held gives a longer path to read.

value 0

Task 4 — acquisition, optional 0 of 10

Click each circle as it appears, as quickly and as accurately as you can. Ten will appear one at a time, and they deliberately differ in size and in how far they sit from the last one. A hand takes measurably longer to reach a small distant circle than a large near one, and the relationship between the two is a straight line with a known slope. A tool that jumps the pointer to a coordinate takes the same time whatever it is aiming at. This one is optional; the report is produced without it.
